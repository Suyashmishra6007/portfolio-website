Currently, What I Am Doing I am currently pursuing my B.Tech from Pranveer Singh Institute of Technology (PSIT), Kanpur. I am a second-year student and actively working to improve my programming, problem-solving, and web-development skills. At present, I am learning Full Stack Development, Data Structures and Algorithms (DSA) using C++, and Java. I am also building my portfolio to showcase my skills, projects, and learning journey.

“Learning, coding, and creating one project at a time.”

First-Year

During my first year of B.Tech, I learned the basics of programming through C and C++. These languages helped me understand fundamental programming concepts such as variables, data types, loops, conditional statements, functions, arrays, pointers, and object-oriented programming.

Learning C and C++ gave me a strong foundation in coding and logical thinking. It also taught me how to approach problems step by step and write structured, efficient programs.

Second Year

In my second year, I am focusing on developing advanced technical skills. I am learning Data Structures and Algorithms using C++, which is helping me understand how to solve problems efficiently. Topics such as arrays, linked lists, stacks, queues, trees, recursion, searching, and sorting are improving my coding ability. Along with DSA, I am learning Full Stack Development to build complete web applications. I am also learning Java to expand my knowledge of object-oriented programming and software development.

Improving my WolfGrey E-commerce Website

Containers are so lightweight that you can run dozens of them on a single laptop simultaneously, each completely isolated from the others. This was simply not practical with virtual machines.

My Project

I have created an e-commerce website named WolfGrey using HTML and CSS. This project helped me apply my front-end development skills and understand how an e-commerce website is designed.

01

Project Overview

WolfGrey is an e-commerce website that I created to practice web design and front-end development. It represents my interest in building real-world web applications.

02

Technologies Used

I developed WolfGrey using HTML and CSS. HTML helped me structure the website, while CSS helped me design the layout, colours, product sections, and overall user interface.

03

Current Project Status

Currently, WolfGrey is a front-end e-commerce website. It focuses on displaying the website design and creating a clean shopping experience for users.

04

Skills Gained

Through this project, I improved my understanding of HTML, CSS, webpage layout, responsive design, and user-interface design. It also helped me learn how to convert an idea into a working website.

05

Future Improvements

After learning backend development, I plan to add user login, product management, shopping cart functionality, order processing, and database integration to make WolfGrey a complete e-commerce platform. Overall Evaluation: WolfGrey is a strong front-end project for my current level. It shows my ability to design and build a website using HTML and CSS, and it has clear potential to become a complete full-stack project.

About B.Tech: When One Container Isn't Enough

B.Tech, or Bachelor of Technology, is not only about studying engineering subjects. It is a journey of learning technology, solving problems, building projects, and developing practical skills. It helps students improve their analytical thinking, creativity, teamwork, and communication.

For me, B.Tech is an opportunity to explore different technologies and prepare for a career in software development. My aim is to continue learning, work on meaningful projects, gain internship experience, and become a skilled software developer in the future.
